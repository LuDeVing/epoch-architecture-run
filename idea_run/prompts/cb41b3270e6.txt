[se4235d62d0] Subtract the streams, add a thirteenth layer: Collapse the residual to one stream with mixing at identity and no write gains, which by the audit changes nothing the head can see, and spend the freed 0.3 GB and the 1.83M parameter headroom on a 13th block. Depth is the one axis the measurements say is under-provisioned, and the frontier recipes keep the stream machinery only because it is cheap behind fused kernels, which this card lacks.
[s39ac7bb6ba] Delay-line residual with signed reads: Reinterpret the stream axis as depth lag: each sublayer reads a signed combination of the current residual and the residuals one, two and three stages earlier, with weights initialized to read only the current one, and writes its branch into the single live residual. Differences between lagged residuals are exactly the last few branch outputs, so a block can add or subtract its recent predecessors per stage, the depth-local version of Attention Residuals and MUDD with zero Sinkhorn and the subtractive mixing the brief says the Birkhoff constraint forbids.
[s3721a39b8a] Multi-timescale residual streams: Keep four streams but make them different by construction: each stream is an exponential moving average over depth of the branch outputs with a fixed decay per stream, one at 1, the others at 0.9, 0.7 and 0.5, and each sublayer and the head read a signed combination initialized to the undecayed stream. Decayed streams have bounded norm and hold a recent-layers view at fixed scale, which gives later blocks a clean signal that the 7.8x-grown main residual buries.
[s8c8bd2c018] Writer-typed streams: Attention writes its output into streams 0 and 1 only and the MLP into streams 2 and 3 only, with the mix at identity and signed reads per sublayer initialized uniform. Attention history and MLP history then live in separate streams instead of superposed in one 384-wide residual, so each consumer can choose how much of the other writer's history it reads, which the identical writes of the current design make impossible.
[se5204f594c] Token-dependent write router: Replace the static write gains with per-token gains from a linear map of the normalized branch output to four logits, so each token decides which streams its branch output enters. Dynamic writes create the stream diversity the static design never builds, which the HC paper showed beats static mixing at expansion four.
[s0dc366cf81] Orthogonal Cayley mixing in place of Sinkhorn: Parameterize each 4x4 mix as the Cayley transform of a learned skew-symmetric matrix, six parameters, which is exactly orthogonal, allows negative entries and starts at exact identity. This removes the 20 iterations and their accumulated approximation error and permits subtractive mixing.
[s6e26ae627a] Strongly asymmetric write init: Raise the diagonal write logits from 0.03 to a larger value a and set the off-diagonal ones to minus a, so attention writes mostly to stream 0 and the MLP mostly to stream 1 from the first step while streams 2 and 3 stay close to the embedding. One constant turns the dead copies into an attention stream, an MLP stream and two embedding skips.
