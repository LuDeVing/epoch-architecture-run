[sb77959ccc2] Depth delay line (permutation mixing): Initialize each stage's mixing logits at a cyclic shift instead of the identity and write the branch output only into the slot that the shift just vacated; stream j then holds the residual state exactly j stages back, so a layer's softmax read can form differences of consecutive states, which are the last three branch outputs individually, at zero added cost. This is a four-deep DenseFormer window built from parts the model already pays for, and the uniform read still equals the plain residual sum because each write lands in exactly one slot and is never lost.
[s408a33cf5e] Depth-band stream init: Change only the write-gate init so stage s of block l writes with weight near 1.9 into stream (2l+s) mod 4 and near 0.1 into the others; the four streams become sums over four interleaved depth bands instead of four near-identical copies. The baseline's 0.03 versus minus 0.01 start gives write weights of 1.015 versus 0.995, so its streams receive identical gradients and the whole four-stream apparatus, the Sinkhorn included, is a cost paid for nothing; breaking the symmetry at init is the cheapest way to make it earn its memory.
[sebdbd7c9e1] Second pass over the middle blocks with pass-specific stream logits: Blocks 4 to 9 are applied twice, so the model spends 18 block applications per token on 12 blocks' weights, and the only new parameters are a second set of mix, read and write logits for the second pass, 56 per block. The stream logits act as the per-loop adapters of relaxed recursive transformers for free, and at 2.4 tokens per parameter the budget is data-limited, so more compute per token with the same weights should buy loss where more weights would not. The looped applications are wrapped in activation checkpointing to stay under 5.6 GB.
[s091040dffb] Progressive stacking from six to twelve blocks: For the first quarter of the steps only blocks 0 to 5 run; at the growth step the model copies each of them into block 6 to 11 and the loop switches to all twelve. The shallow phase learns the unigram and bigram structure at 0.7 times the step cost and a steeper per-token slope, and the copied stack starts from a trained function rather than a cold one, which the stacking literature reports as 1.5 to 2 times token efficiency.
[s5a05cc1d3b] Parallel tail with stream-separated writes: In the last three blocks attention and MLP read the same normalized state and run in parallel, and each writes into its own stream instead of into the same residual, so the two branches cannot cancel and the next stage's read can weight them separately. The redundancy profile of deep layers says late blocks are near-identity, so sequential ordering there buys little; the parallel layout also drops one Sinkhorn, one read and one combine per block, which lowers step time and activation memory.
[s4801b35fe3] Per-token write gates: Each stage multiplies its branch output by a sigmoid of a learned vector dotted with the normalized stage input, with a bias so the gate starts at 0.95; the gate vector is 1-D so it falls to AdamW. Easy tokens can then damp late-layer writes that add noise to a prediction already made, and the model's late-layer capacity concentrates on hard tokens without any routing, skipping or lost KV entries.
[s941f0a2098] Ten blocks of width 1300: Set n_layer to 10 and d_ff to 1300, which keeps non-embedding parameters at 20.9M, below the baseline.
