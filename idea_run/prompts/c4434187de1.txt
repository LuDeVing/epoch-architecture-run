[s4e7c7db5f2] Embedding RMSNorm (input scale decoupled from the tied head): Add an RMSNorm with learned gain directly after the token lookup, so every token enters the four streams at unit RMS. With tied embeddings the row norms of E are set by the head gradient and AdamW decay, so rare tokens enter at a fraction of the scale of frequent ones and are drowned by the first branch writes; the norm removes that coupling without touching the head.
[s947cf0f791] QK-norm gain init above 1 (uncapping the attention logit): After QK RMSNorm the content logit is bounded by 64*g_q*g_k/sqrt(96) = 6.5 at gain 1, and the gains must grow under AdamW at 3e-3 per step against decay 0.1 before any head can attend sharply over 1024 positions. Initializing the q and k norm gains at g > 1 gives the sharp regime from step 0 (the speedrun found 1.36x the default scale optimal after QK-norm).
[scb6b27cfa6] Final-norm gain at zero (zero-init head through the tie): The head is tied so it cannot be zero-initialized, but logits = gain * x_hat * E, so a final-norm gain of 0 gives uniform logits at step 0. Both Muon and Adam are scale-invariant to gradient magnitude, so the body trains at full speed while the gain grows, and the soft early targets remove the noise the random 0.39-std logits inject into the first hundred updates.
[sb69220affc] Smaller init for Muon-trained matrices: A 384x384 Gaussian at std 0.02 has spectral norm 0.78 while a Muon step has spectral norm 0.02, so the random dominant directions survive for roughly 40 steps and afterward decay only through weight decay, lingering as a 10% random component at the end. Shrinking the input-projection init (wq, compress, expand, rotary, w_gate, w_up) to std 0.01 or 0.005 halves the junk without changing the branch scaling.
[s9ca5ee94d0] Multi-timescale streams (subtract the identical copies, reinvest in graded write rates): Removal: the near-symmetric write start, which keeps all four streams within 2% of each other so three of them are copies that cost memory and buy nothing. Reinvestment: initialize the write logits so the streams receive each branch at weights 1.6, 0.8, 0.4, 0.2, making stream 3 a slow near-embedding channel and stream 0 a fast accumulator, so each layer's read softmax can choose between recent and ancient state, the same role the Attention Residuals of Kimi K3 play without their cost.
[s2da3e1c4b5] No-affine norms with one scalar temperature each (subtract the gain vectors): Removal: every per-channel norm gain (9,600 params), which modded-nanogpt shows are unnecessary and which AdamW decay pulls toward zero all run. Reinvestment: each norm keeps a single scalar, initialized so the attention temperature starts at 1.4x and the MLP gate pre-activation at the current scale, because these two temperatures are the only scales Muon's uniform-singular-value updates cannot set cheaply.
[sf46adba8d2] Magnitude-aware head temperature (subtract scale-freeness at the final norm): Removal: the final RMSNorm throws away the residual magnitude, so a token whose residual grew large from many confident writes gets the same logit temperature as one the layers barely touched. Reinvestment: multiply the final normalized output by exp(a * (log RMS - m)) with scalars a (init 0) and m, so the model can sharpen confident tokens and hedge uncertain ones. The null case is exactly the baseline.
