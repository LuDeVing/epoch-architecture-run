TECHNIQUES:
K0: DenseFormer (depth-weighted averaging): After each block, the model takes a learned weighted average of the current output and all earlier block outputs, so later layers can read earlier states directly.
K1: MUDDFormer (multiway dynamic dense connections): Dense cross-layer connections whose weights are computed from the hidden state at each position, with separate connections for the query, key, value and residual inputs of each block.
K2: Attention Residuals (Kimi, AttnRes / Block AttnRes): Each layer replaces the fixed unit-weight residual sum with softmax attention over earlier layer outputs, using a learned pseudo-query per layer and RMSNorm on the keys. The block variant groups layer
K3: Value Residual Learning (ResFormer / SVFormer): Each layer's value vectors get a residual connection to the first layer's values, so deep layers keep token-level information. SVFormer instead shares the first layer's values across all layers.
K4: modded-nanogpt U-Net skips and value embeddings: Skip connections from the embedding to every block and from block 3 to block 6. Extra token-embedding tables are mixed into attention values, with the skip weights gated by a sigmoid.
K5: Mixture-of-Recursions (MoR): Recursive blocks with shared weights, plus a per-token router that picks how many recursions each token gets. Attention and KV cache cover only the tokens still active at each depth.
K6: Relaxed Recursive Transformers (shared layers plus layer-wise LoRA): Layers are tied into a looped block, and per-loop low-rank adapters restore layer specialization.
K7: Looped GPT-BERT (depth-wise sharing for tiny models): Four physical layers are applied over twelve recurrent passes to trade parameters for compute.
K8: Parallel attention+MLP blocks (PaLM-style): Attention and MLP read the same normalised input and their outputs are summed, instead of running in sequence.
K9: Depth–width scaling for small models (Nemotron-Flash): Extends scaling laws to loss as a function of both depth and width, so the depth/width ratio can be chosen from profiled configurations.
