K0: Partial RoPE (rotate only a fraction of dims): Apply rotary to only a small slice of each head's dimensions and leave the rest position-free.
K1: LeRoPE: learnable per-frequency RoPE: Learn one scalar per rotary frequency instead of using a fixed geometric sequence from base theta.
K2: Partial RoPE (50% of head dims) in modded-nanoGPT: Rotate half the head dims. The long sliding windows attend mostly to the unrotated (stationary) dims.
K3: QK-Norm in the speedrun recipe: RMS-normalize queries and keys before the dot product.
K4: Partial RoPE with layer-wise LN scale (Parameter Golf): Rotate only part of q and k, typically the first half, so the remaining dims learn position-agnostic features. It was paired with layer-wise LayerNorm scaling.
K5: QKNorm with a learnable scale g: L2-normalize q and k, then multiply the logits by a learnable scalar g instead of dividing by sqrt(d).
K6: Scalable-Softmax (SSMax): Scale the logits by s·log n, with a learnable s, so that attention does not flatten as context n grows.
K7: Head-specific sigmoid output gate after SDPA: A query-dependent sigmoid gate on the attention output adds non-linearity and sparsity.
K8: Slowing upper-layer Q/K learning early in training: Temporarily lower the learning rate on only the upper-layer query/key projections so attention does not sharpen before lower-layer features stabilize.
