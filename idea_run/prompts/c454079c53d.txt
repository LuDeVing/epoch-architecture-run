TECHNIQUES:
K0: TransMLA expressiveness argument (MLA vs GQA at equal KV cache): GQA can always be rewritten as an MLA with the same KV cache size, but MLA cannot always be rewritten as GQA, so MLA is strictly more expressive per cached dimension.
K1: Latent MHA for small language models (MLA + RoPE, half-rank latent): MLA with the latent rank set to half the hidden size, with RoPE applied to the decompressed q/k.
K2: Low-Rank Key Value Attention (LRKV): Each layer has one shared full-rank K/V projection, and each head adds a small trainable low-rank residual. This keeps head diversity while sharing most of the KV.
K3: Grouped-Tied Attention (GTA) and Grouped Latent Attention (GLA): GTA ties key and value into one state per query-head group, using the full tied state as the value. GLA is a latent attention variant that is easier to shard.
K4: Tensor Product Attention (TPA): Q, K and V are factorized into input-dependent low-rank tensor-product components. This is natively compatible with RoPE, unlike MLA's extra decoupled RoPE parameters.
K5: Decoupled RoPE in MLA (shared rotary sub-vector): A single rotary sub-vector is shared across heads, so position information bypasses the latent compression.
K6: Multi-head Temporal Latent Attention (MTLA): Adds compression along the time axis on top of MLA's latent compression. A hyper-network merges temporally adjacent KV vectors, and a stride-aware causal mask keeps training parallel.
K7: DeepSeek-V4 shared-KV compressed attention (CSA/HCA): Key and value share one vector (2x KV reduction). Token blocks are compressed about 4x (CSA) or about 128x (HCA), with top-k sparse selection and a 128-token sliding window.
F0: MLA without RoPE at small scale: Without RoPE, MLA trailed vanilla MHA by 3-5% in validation loss at 30M parameters. Position handling therefore matters more than latent width when the model is small.
F1: Uniform latent rank across layers (CARE paper, MLA conversion): Giving every layer the same rank causes activation drift and worse attention fidelity. Per-layer rank allocation helps. This was shown for converting pretrained models to MLA, not for training from sc
F2: GQA/MQA-style KV sharing for quality: Sharing KV across heads reduces memory but constrains head-level diversity. Both LRKV and TransMLA position GQA/MQA as quality-losing at matched cache, so sharing is not a free win.
