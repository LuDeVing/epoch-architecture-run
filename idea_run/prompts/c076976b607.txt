[s9672073260] Shifted-key heads (one-hop induction): For heads 3 to 5, the key at position j is the (post-RoPE) key of token j−1 while the value stays token j's; a query that matches "the token before me last time" directly reads "what followed it". Today this needs two layers (a previous-token head feeding an induction head); fusing it frees those layers for other circuits and should lower loss on repeated spans within 1024 tokens.
[se7dbbff80d] Latent-value heads (per-head rank-128 output maps): Drop the V half of expand and the shared wo; each head aggregates the 128-d normalized latent directly as its value and writes it through its own 384×128 map. Today each head's value-to-output path is wo_h·E_v,h, rank 64 even though the latent has 128 dims; the cap is paid for nothing because at 6 heads the concatenation never uses the extra rank. DeepSeek-style absorption makes this free at inference; here it is applied at training time to raise per-head rank.
[sccd3b774dd] Re-query hop (two retrievals per layer, shared K/V): After the first SDPA, feed the concatenated head output y through the existing wq and q_norm to form a second query and attend once more to the same K and V, then apply wo to the second result (first result added as a skip). A composition like "find the entity, then find what it did" takes two layers today; with shared K/V the second hop costs no parameters and lets 12 layers act like 24 hops for retrieval.
[se8e7ae41f1] Two-depth keys (queries see the previous layer's K/V too): Each layer concatenates its own K and V with the previous layer's K and V along the key axis and runs one softmax over 2T keys with a causal mask repeated twice. The query chooses depth as well as position, so a feature the stream overwrote between layers is still retrievable, and attention patterns can specialise by depth without doubling layers.
[s87a5de12d1] Learned sink key per head: Prepend a learned 96-d key per head and a zero value, plus a dummy zero query row so is_causal still aligns; every query can dump mass on the sink instead of on token 0. MiMo's ablation shows a measurable gain, and this architecture has no sink mechanism yet, so the first-token attention mass is wasted on an arbitrary token.
[s22ef52ba6b] Cheap per-head output gate: Multiply each head's SDPA output by sigmoid(x_norm[:, :, :32]·W_h) before wo, where x_norm is the attention input already in Attention.forward; the gate makes the head's write conditional on the token so a head can abstain instead of writing noise. This is the open test the brief asks for: whether the Qwen gate interacts with QK-norm and four-stream mixing, and whether it flattens the 10x layer-0 attention gradient.
[s42e96f80d8] Three heads of 128: Set n_head=3 so each head's content key is 128-d, matching the latent width; today a 64-d head key is a rank-64 slice of a 128-d latent, and the Pythia ablation says the penalty from small QK dims is the one head-size effect that is not neutral. Fewer heads also cut SDPA and wq cost.
