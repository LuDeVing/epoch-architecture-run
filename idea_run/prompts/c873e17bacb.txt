TECHNIQUES:
K0: Head-specific sigmoid gate on SDPA output (Gated Attention, Qwen): Multiply each head's SDPA output elementwise by sigmoid(X·Wθ), computed from the layer input, before the output projection.
K1: Sparse per-head attention gate on 12 residual channels (modded-nanoGPT speedrun): Each head's output gets a sigmoid gate fed only by the first 12 dimensions of the residual stream, which is a very cheap gate.
K2: Value embeddings with per-head gate (speedrun and nanochat): Extra token embeddings are mixed into attention values, often on alternating layers. The nanochat variant gates them per head from the first 32 input channels with a 2·sigmoid range.
K3: Long-short sliding-window attention pattern: Alternate short-window and long-window layers, with window-size warmup and YaRN, instead of full context everywhere.
K4: Value Residual Learning (ResFormer / SVFormer): Add a residual path from the first layer's value vectors to the values of every later layer. SVFormer shares the first layer's values across all layers.
K5: NormFormer HeadScale: Scale each head's output by a learned scalar, initialized at 1, before the output projection. Combined with extra norms to balance gradient magnitudes between early and late layers.
K6: Grouped low-rank output projection (DeepSeek-V4): Split head outputs into groups, project each group to a smaller intermediate dimension, then combine and project to the hidden size.
K7: MLA vs MHA vs GQA vs GTA/GLA at fixed query-head count: Compare KV-sharing schemes (MHA, GQA-4, MQA, GTA, MLA, GLA) with FFN width and 12 query heads held fixed.
K8: Differential attention: Subtract two softmax attention maps to cancel common-mode noise and sparsify attention.
K9: Talking-heads attention: Learned linear mixing across the head dimension of the attention logits, before and after the softmax.

F1: Changing head count at fixed hidden size (PanGu-π Pro): The authors report that head count and head dimension (they use 128) do not noticeably affect speed or accuracy when hidden size is fixed. This suggests head-split tuning may be near-neutral.
